# 智能 AI 景区用户管理系统

一个面向景区管理方的简单智能 AI 景区用户管理系统，用于统一管理游客信息、预约记录、游览数据和用户服务，提高景区运营管理效率与游客体验。

## 项目简介

本系统以景区用户管理为核心，结合基础 AI 能力，为景区工作人员提供便捷的用户信息维护、游客预约管理、数据查询和智能服务功能。

系统适合用于：

- 景区游客信息管理
- 门票预约与订单管理
- 游客画像和行为分析
- 景区通知与消息推送
- 游客咨询和智能问答
- 景区运营数据统计

## 主要功能

### 1. 用户管理

- 用户注册、登录和退出
- 游客基本信息维护
- 用户身份和权限管理
- 用户状态管理
- 用户信息查询与模糊搜索

### 2. 预约管理

- 景区门票预约
- 入园日期和时段管理
- 预约记录查询
- 预约审核与取消
- 余票信息展示

### 3. 订单管理

- 门票订单创建
- 订单状态查询
- 订单取消与退款记录
- 订单详情查看
- 消费数据统计

### 4. AI 智能服务

- 景区智能问答
- 游览路线推荐
- 根据游客偏好推荐景点
- 常见问题自动回复
- 游客需求分析

> AI 功能可根据实际部署环境接入对应的大语言模型或第三方智能服务。

### 5. 景区信息管理

- 景点信息维护
- 开放时间管理
- 门票价格管理
- 景区公告发布
- 景区活动管理

### 6. 数据统计

- 日、周、月游客数量统计
- 预约和订单数据统计
- 热门景点排行
- 用户访问趋势分析
- 景区运营数据看板

## 系统角色

| 角色 | 主要权限 |
| --- | --- |
| 游客 | 注册登录、浏览景区信息、预约门票、查看订单、使用 AI 咨询 |
| 景区工作人员 | 管理游客、处理预约订单、发布公告、维护景区信息 |
| 系统管理员 | 用户权限管理、系统配置、数据统计和系统维护 |

## 技术架构

项目可根据实际开发需求采用前后端分离架构：

- **前端**：Vue / React + JavaScript 或 TypeScript
- **后端**：Spring Boot / Node.js / Django
- **数据库**：MySQL 或 PostgreSQL
- **缓存**：Redis
- **AI 服务**：大语言模型 API 或本地部署模型
- **接口规范**：RESTful API

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/TI-cia-886/smart-secnic.git
cd smart-secnic
```

### 2. 初始化数据库

创建数据库后，执行 `database/schema.sql`（如果项目中提供）完成基础表结构初始化，并根据本地环境修改数据库连接配置。

### 3. 启动后端服务

```bash
cd backend
# 根据实际项目构建工具执行
mvn spring-boot:run
```

### 4. 启动前端服务

```bash
cd frontend
npm install
npm run dev
```

> 当前仓库处于基础 README 阶段，实际启动命令、目录结构和配置项请以后续代码实现为准。

## 数据库核心表设计

- `scenic_spots`：景点信息
- `tickets`：门票信息
- `reservations`：预约记录
- `orders`：订单信息
- `announcements`：景区公告
- `ai_conversations`：AI 对话记录

## AI 使用说明

系统中的 AI 能力可以用于回答景区开放时间、票价、交通路线、游览建议等常见问题。接入真实 AI 服务时，建议：

1. 将 API Key 保存在环境变量或安全配置中心中。
2. 不要在前端代码或 Git 仓库中直接提交敏感密钥。
3. 对用户输入进行长度限制和内容安全校验。
4. 对 AI 返回结果进行必要的审核和兜底处理。
5. 注意保护游客姓名、手机号等个人信息。
